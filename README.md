# 🚀 Rick and Morty API Explorer

Um projeto front-end interativo para explorar os personagens do universo de Rick and Morty. Este projeto foi desenvolvido com um forte foco no aprimoramento prático de habilidades em JavaScript moderno, lidando com requisições assíncronas, manipulação de interface e tratamento de dados.

🔗 **[Acesse o projeto ao vivo aqui](https://lidiavidal.github.io/API-RickAndMorty/)**

---

## 🧠 Destaques de Aprendizado (JavaScript)

O grande foco e diferencial deste projeto foi o uso de **JavaScript Vanilla**. Durante o desenvolvimento, pude aprofundar e consolidar os seguintes conceitos:

### 1. Consumo de API 🌐
* **Como funciona:** O projeto se conecta à [The Rick and Morty API](https://rickandmortyapi.com/) para buscar os dados oficiais da série.
* **O que aprendi:** Pratiquei requisições HTTP assíncronas (utilizando `fetch`), lidando com as respostas da rede, transformando os dados recebidos em `.json()` e extraindo apenas as informações relevantes para a aplicação.

### 2. Manipulação do DOM 🎨
* **Como funciona:** A interface é construída dinamicamente baseada nos dados recebidos da API.
* **O que aprendi:** Como selecionar elementos no HTML, criar novos elementos na memória e inseri-los na página de forma dinâmica. Os "cards" dos personagens não estão fixos no HTML; eles são gerados pelo JavaScript em tempo de execução, integrando imagens, nomes e status de vida perfeitamente na estrutura.

### 3. Filtros Avançados com `filter()` 🔍
* **Como funciona:** Permite que o usuário encontre personagens específicos com base em categorias.
* **O que aprendi:** Aplicação prática de High-Order Functions de arrays. O uso do `.filter()` foi essencial para criar a lógica que percorre a lista de personagens recebida e retorna apenas aqueles que correspondem aos critérios de busca exatos, atualizando o DOM em seguida apenas com os resultados filtrados.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica.
* **CSS3:** Estilização e responsividade da interface.
